# Changelog

All notable changes to the Digital Business Card Template will be documented in this file.

The format is based on Keep a Changelog, and this project follows Semantic Versioning.

## [Unreleased]

### Added

- React, TypeScript, Vite, and Tailwind CSS project foundation
- Central typed card configuration
- Five configurable theme presets
- Built-in social and contact icon registry
- Configurable profile, primary action, social links, sharing, and QR code
- Optional decorative divider and background image support
- Runtime configuration validation
- Automated tests for card behaviour, themes, sharing, metadata, and validation
- Repository contribution, conduct, and security guidelines

### Changed

- Replaced Vite starter branding with neutral template assets

### Fixed

- Dynamic icon rendering now passes React static-component lint rules
